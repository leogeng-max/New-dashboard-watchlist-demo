# Intelligent Investing — new-user flow (prototype)

The onboarding film, then the three screens a new user meets:

- **New user exploration 2**: the first open after sign-up. The film plays, then the page opens out of the ring.
- **Demo account**: the dashboard on sample data, with Active Positions version 21.
- **Watchlist view**: a later visit, before any capital is deployed.

Pick a screen from the menu at the top left. Best viewed on desktop; the phone frame is the app.

## Files

| File | What it is |
|---|---|
| `index.html` | The prototype. |
| `onboarding-film.mp4` | The film the page plays first. It must stay next to `index.html`. |
| `stock.html` | The stock page that opens when you tap a position. |

All data is illustrative. No real accounts, investments or transactions are involved.
